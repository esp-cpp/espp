VL53L5CX Multizone ToF Sensor

The VL53L5CX is a multizone Time-of-Flight (ToF) sensor: it ranges up to 4 meters in every zone of a 4x4 or 8x8 grid over a 63 degree diagonal field of view, at up to 60 Hz (4x4) or 15 Hz (8x8). Every zone reports a distance, signal and ambient rates, a sigma, a reflectance estimate and a validity status, and the sensor can run a motion indicator over the zones.

The sensor has no firmware in ROM: the driver uploads the firmware (bundled, from STMicroelectronics’ Ultra Lite Driver, BSD-3-Clause) over I2C at every initialization, which takes about two seconds at 400 kHz. The driver is a port of ST’s Ultra Lite Driver 1.1.2 to the espp peripheral conventions; one target per zone is supported, and the crosstalk calibration / detection threshold plugins are not ported yet.

Note

The VL53L5CX shares this component with the single-zone VL53L4CD / VL53L4CX driver (both use 16-bit register addresses), but the two drivers share nothing else.

Web console

espp::Vl53l5cxService (vl53l5cx_service.hpp) exposes a sensor over the dispatcher / stream_frame protocol (module id 10, protocol id espp.vl53l5cx, see vl53l5cx_protocol.hpp): a host can configure every setting, start / stop ranging and receive each ranging frame. The hosted VL53L5CX console web app (components/vl53l/web/vl53l5cx_console.html) draws the frames as a live 3D surface or bar height field over WebUSB / Web Serial; the VL53L5CX Web Console Example runs it next to the standard USB services.

Classes

class Vl53l5cx : public espp::BasePeripheral<uint16_t, true>

VL53L5CX / VL53L7CX multizone Time-of-Flight ranging sensor (4x4 / 8x8 zones)

The VL53L5CX is a Time-of-Flight (ToF) sensor with a 63 degree diagonal field of view (the VL53L7CX: the same sensor with a 90 degree field of view) that ranges up to 4 m in every zone of a 4x4 or 8x8 grid, at up to 60 Hz (4x4) or 15 Hz (8x8). Every zone reports a distance, a signal / ambient rate, a sigma, a reflectance estimate and a validity status; the sensor can also run a motion indicator over the zones.

The sensor has no ROM firmware: this driver uploads the ~84 KB VL53L5CX firmware (STMicroelectronics, bundled, see the BSD-3-Clause notice in the sources) over I2C at every initialize(), then talks to it through the “DCI” command interface. Initialization takes about two seconds at 400 kHz (the sensor supports I2C Fast Mode Plus, 1 MHz). The logic is a port of ST’s Ultra Lite Driver (ULD) 1.1.2.

Results are reported per zone in row-major order (`zone = row * width + col`, width 4 or 8); for the physical orientation of zone 0 see UM2884 (“Ranging data arrangement”).

See also

https://www.st.com/en/imaging-and-photonics-solutions/vl53l5cx.html

See also

UM2884 “A guide to using the VL53L5CX multizone Time-of-Flight ranging

sensor with wide field of view Ultra Lite Driver (ULD)”

Example

  // make the i2c we'll use to communicate
  static constexpr auto i2c_port = I2C_NUM_0;
  static constexpr auto i2c_clock_speed = CONFIG_EXAMPLE_I2C_CLOCK_SPEED_HZ;
  static constexpr gpio_num_t i2c_sda = (gpio_num_t)CONFIG_EXAMPLE_I2C_SDA_GPIO;
  static constexpr gpio_num_t i2c_scl = (gpio_num_t)CONFIG_EXAMPLE_I2C_SCL_GPIO;
  logger.info("Creating I2C on port {} with SDA {} and SCL {} at {} Hz", i2c_port, i2c_sda, i2c_scl,
              i2c_clock_speed);
  // The transaction timeout must cover the driver's longest transfers (512-byte
  // firmware chunks, ~1.4 KB result frames): derived from the clock
  static constexpr int i2c_timeout_ms = espp::Vl53l5cx::i2c_timeout_ms(i2c_clock_speed);
  espp::I2c i2c({.port = i2c_port,
                 .sda_io_num = i2c_sda,
                 .scl_io_num = i2c_scl,
                 .sda_pullup_en = GPIO_PULLUP_ENABLE,
                 .scl_pullup_en = GPIO_PULLUP_ENABLE,
                 .timeout_ms = i2c_timeout_ms,
                 .clk_speed = i2c_clock_speed});
  std::error_code ec;

  // the constructor reboots the sensor and uploads its firmware (about two
  // seconds at 400 kHz). The callbacks take the address from the driver, so
  // set_i2c_address() keeps working (a per-device adapter would not).
  espp::Vl53l5cx sensor(espp::Vl53l5cx::Config {
    .device_address = espp::Vl53l5cx::DEFAULT_ADDRESS,
#if CONFIG_EXAMPLE_VARIANT_VL53L7CX
    .variant = espp::Vl53l5cx::Variant::VL53L7CX,
#else
      .variant = espp::Vl53l5cx::Variant::VL53L5CX,
#endif
    .write = [&i2c](uint8_t address, const uint8_t *data,
                    size_t length) { return i2c.write(address, data, length); },
    .read = [&i2c](uint8_t address, uint8_t *data,
                   size_t length) { return i2c.read(address, data, length); },
    .log_level = espp::Logger::Verbosity::INFO,
  });
  if (!sensor.is_initialized()) {
    logger.error("The VL53L5CX did not initialize; check the wiring and the address");
    return;
  }

  // resolution first (it bounds the ranging frequency), then the frame rate
#if CONFIG_EXAMPLE_RESOLUTION_8X8
  const auto resolution = espp::Vl53l5cx::Resolution::ZONES_8X8;
#else
  const auto resolution = espp::Vl53l5cx::Resolution::ZONES_4X4;
#endif
  if (!sensor.set_resolution(resolution, ec)) {
    logger.error("Failed to set the resolution: {}", ec.message());
    return;
  }
  if (!sensor.set_ranging_frequency_hz(CONFIG_EXAMPLE_RANGING_FREQUENCY_HZ, ec)) {
    logger.error("Failed to set the ranging frequency: {}", ec.message());
    return;
  }
#if CONFIG_EXAMPLE_MOTION_INDICATOR
  if (!sensor.enable_motion_indicator(CONFIG_EXAMPLE_MOTION_MIN_MM, CONFIG_EXAMPLE_MOTION_MAX_MM,
                                      ec)) {
    logger.error("Failed to enable the motion indicator: {}", ec.message());
    return;
  }
#endif
  if (!sensor.start_ranging(ec)) {
    logger.error("Failed to start ranging: {}", ec.message());
    return;
  }

  // poll for frames and print the distance grid (mm; "----" where the zone
  // has no valid target, with a summary of why). A plain task rather than a
  // periodic timer: a frame read is ~1.4 KB of I2C (about 40 ms at 400 kHz),
  // far longer than a sensible data-ready poll interval.
  espp::Vl53l5cx::RangingData frame;
  espp::Task poll_task({
      .callback = [&](std::mutex &m, std::condition_variable &cv) -> bool {
        std::error_code ec;
        if (!sensor.is_data_ready(ec)) {
          // nothing new yet (an I2C error is logged by the driver); check again soon
          std::unique_lock<std::mutex> lock(m);
          cv.wait_for(lock, 5ms);
          return false;
        }
        if (!sensor.get_ranging_data(frame, ec)) {
          logger.error("Failed to read the frame: {}", ec.message());
          return false;
        }
        std::string grid;
        std::map<espp::Vl53l5cx::TargetStatus, int> invalid;
        for (size_t row = 0; row < frame.width(); row++) {
          for (size_t col = 0; col < frame.width(); col++) {
            const size_t zone = frame.zone_index(row, col);
            if (frame.is_valid(zone)) {
              grid += fmt::format("{:5d}", frame.distance_mm[zone]);
            } else {
              grid += " ----";
              invalid[frame.status(zone)]++;
            }
          }
          grid += "\n";
        }
        std::string why;
        for (const auto &[status, count] : invalid) {
          why += fmt::format("  {} x {} ({})", count, static_cast<int>(status),
                             espp::Vl53l5cx::target_status_name(status));
        }
        fmt::print("{}{} / {} zones valid{}\n", grid, frame.num_zones() - invalid_total(invalid),
                   frame.num_zones(), why.empty() ? "" : ";" + why);
#if CONFIG_EXAMPLE_MOTION_INDICATOR
        const auto &motion = frame.motion_indicator;
        const size_t aggregates = std::min<size_t>(motion.nb_of_aggregates, motion.motion.size());
        fmt::print("motion: global {} {} status {} detected {}/{} aggregates:{}\n",
                   motion.global_indicator_1, motion.global_indicator_2, motion.status,
                   motion.nb_of_detected_aggregates, motion.nb_of_aggregates,
                   fmt::join(motion.motion.begin(), motion.motion.begin() + aggregates, " "));
#endif
        fmt::print("\n");
        return false; // keep polling
      },
      .task_config = {.name = "vl53l5cx poll", .stack_size_bytes = 6 * 1024},
      .log_level = espp::Logger::Verbosity::WARN,
  });
  poll_task.start();

Note

The VL53L5CX and VL53L7CX answer the same device / revision ids and take different firmware images: Config::variant selects the image, and a wrong one fails at the first firmware command after boot (the NVM read) with a firmware error. There is no way to tell the parts apart over I2C.

Note

The communication uses 16-bit register addresses, like the VL53L4 driver (espp::Vl53l) in this component, but the two devices share nothing else: use espp::Vl53l for the VL53L4CD / VL53L4CX single-zone sensors.

Note

Only one target per zone is supported (the ULD default); the crosstalk calibration and detection threshold plugins of the ULD are not ported (the default crosstalk shape is loaded).

class Vl53l5cxService : public espp::BaseComponent

Dispatcher service exposing an espp::Vl53l5cx over the VL53L5CX console protocol (module 10 by default).

Requests are executed against the driver under the sensor mutex (a settings write is a few DCI transactions, an INITIALIZE re-uploads the firmware for about two seconds, so feed this service from a worker task, e.g. an espp::DispatcherWorker) and the reply is sent after the mutex is released. Frames arrive through on_frame() from the application’s poll task and are forwarded (every Nth, see SetFrameStream) while the host has the stream enabled; the latest one is kept for GetFrame. A STATUS snapshot reads every setting back from the sensor (seven DCI reads; allowed while ranging).

Vl53l5cxService Example

  // Vendor (WebUSB) and CDC (Web Serial) are independent byte streams, so each
  // gets its own Vl53l5cxService (replies and the frame stream go back on the
  // stream the host is using) and its own DispatcherWorker (one bounded RX
  // queue + worker task feeding one parser, so the blocking sensor command
  // handler never runs in the TinyUSB callback context). Both services share
  // the one driver and its mutex; the poll task below feeds both.
  //
  // Each transport's `send` is called from TWO tasks -- the dispatcher worker
  // (request + discovery replies) and the poll task (the frame stream) -- and
  // UsbDevice's write_*() do not serialize writers, so guard each with a mutex
  // to keep frames atomic on the wire.
  std::mutex tx_mutex;
  auto vendor_send = [&](std::span<const uint8_t> f) {
    std::lock_guard<std::mutex> lock(tx_mutex);
    if (!usb.write_vendor(f))
      logger.warn_rate_limited("dropped a {}-byte vendor frame (TX backpressure)", f.size());
  };
  auto cdc_send = [&](std::span<const uint8_t> f) {
    std::lock_guard<std::mutex> lock(tx_mutex);
    if (!usb.write_cdc(f))
      logger.warn_rate_limited("dropped a {}-byte CDC frame (TX backpressure)", f.size());
  };
  espp::Vl53l5cxService vendor_service(sensor, {.send = vendor_send,
                                                .sensor_mutex = &sensor_mutex,
                                                .log_level = espp::Logger::Verbosity::INFO});
  espp::Vl53l5cxService cdc_service(sensor, {.send = cdc_send,
                                             .sensor_mutex = &sensor_mutex,
                                             .log_level = espp::Logger::Verbosity::INFO});

  // The standard services (system 7 / monitor 8 / OTA 0 / core dump 4), one per
  // transport through the same mutex-guarded senders. A reboot request is
  // permitted as is (the sensor is re-initialized at boot).
  auto reboot_request = [&](espp::SystemService::RebootKind kind) {
    logger.warn("Host requested a {}; allowing it",
                kind == espp::SystemService::RebootKind::Bootloader ? "reboot into the bootloader"
                                                                    : "reboot");
    return true;
  };
  espp::SystemService vendor_system({.send = vendor_send,
                                     .on_reboot_request = reboot_request,
                                     .log_level = espp::Logger::Verbosity::INFO});
  espp::SystemService cdc_system({.send = cdc_send,
                                  .on_reboot_request = reboot_request,
                                  .log_level = espp::Logger::Verbosity::INFO});
  espp::MonitorService vendor_monitor(
      {.send = vendor_send,
       .task_config = {.name = "monitor_v", .stack_size_bytes = 6 * 1024},
       .log_level = espp::Logger::Verbosity::INFO});
  espp::MonitorService cdc_monitor(
      {.send = cdc_send,
       .task_config = {.name = "monitor_c", .stack_size_bytes = 6 * 1024},
       .log_level = espp::Logger::Verbosity::INFO});
  espp::OtaService vendor_ota(ota,
                              {.send = vendor_send, .log_level = espp::Logger::Verbosity::INFO});
  espp::OtaService cdc_ota(ota, {.send = cdc_send, .log_level = espp::Logger::Verbosity::INFO});
  espp::CoreDumpService vendor_coredump(
      core_dump, {.send = vendor_send, .log_level = espp::Logger::Verbosity::INFO});
  espp::CoreDumpService cdc_coredump(
      core_dump, {.send = cdc_send, .log_level = espp::Logger::Verbosity::INFO});

  // On an RX overflow the OTA service aborts a transfer it owned and tells the
  // host (an OTA image with dropped bytes is unusable).
  espp::DispatcherWorker vendor_link(
      {.send = vendor_send,
       .on_overflow = [&]() { vendor_ota.on_rx_overflow(); },
       .task_config = {.name = "vl53l5cx_vendor", .stack_size_bytes = 16384}});
  espp::DispatcherWorker cdc_link(
      {.send = cdc_send,
       .on_overflow = [&]() { cdc_ota.on_rx_overflow(); },
       .task_config = {.name = "vl53l5cx_cdc", .stack_size_bytes = 16384}});
  vendor_link.register_module(vendor_service); // module 10 + its discovery metadata
  cdc_link.register_module(cdc_service);
  vendor_link.register_module(vendor_system);
  vendor_link.register_module(vendor_monitor);
  vendor_link.register_module(vendor_ota);
  vendor_link.register_module(vendor_coredump);
  cdc_link.register_module(cdc_system);
  cdc_link.register_module(cdc_monitor);
  cdc_link.register_module(cdc_ota);
  cdc_link.register_module(cdc_coredump);
  vendor_link.serve_discovery(usb_cfg.product);
  cdc_link.serve_discovery(usb_cfg.product);

  // The TinyUSB callbacks just queue bytes for the workers.
  usb.set_vendor_receive_callback([&](std::span<const uint8_t> data) { vendor_link.push(data); });
  usb.set_cdc_receive_callback([&](std::span<const uint8_t> data) { cdc_link.push(data); });

  // The one poll loop: read every frame the sensor produces (a frame read is
  // ~1.4 KB of I2C, about 40 ms at 400 kHz) and hand it to both services,
  // which forward it on the transport(s) whose host enabled the stream.
  espp::Vl53l5cx::RangingData frame;
  uint32_t frames = 0;
  auto last_report = std::chrono::steady_clock::now();
  espp::Task poll_task({
      .callback = [&](std::mutex &m, std::condition_variable &cv) -> bool {
        if (!sensor.is_initialized() || !sensor.is_ranging()) {
          std::unique_lock<std::mutex> lock(m);
          cv.wait_for(lock, 50ms);
          return false;
        }
        bool have_frame = false;
        {
          std::lock_guard<std::mutex> lock(sensor_mutex);
          std::error_code ec;
          if (sensor.is_data_ready(ec)) {
            have_frame = sensor.get_ranging_data(frame, ec);
            if (!have_frame)
              logger.warn_rate_limited("Failed to read a frame: {}", ec.message());
          }
        }
        if (!have_frame) {
          // nothing new yet (an I2C error is logged by the driver); check again soon
          std::unique_lock<std::mutex> lock(m);
          cv.wait_for(lock, 3ms);
          return false;
        }
        vendor_service.on_frame(frame);
        cdc_service.on_frame(frame);
        frames++;
        const auto now = std::chrono::steady_clock::now();
        if (now - last_report >= 10s) {
          logger.info("{} frames read ({} zones); vendor stream {}, CDC stream {}", frames,
                      frame.num_zones(), vendor_service.stream_enabled() ? "on" : "off",
                      cdc_service.stream_enabled() ? "on" : "off");
          last_report = now;
        }
        return false; // keep polling
      },
      .task_config = {.name = "vl53l5cx poll", .stack_size_bytes = 8 * 1024},
      .log_level = espp::Logger::Verbosity::WARN,
  });
  poll_task.start();

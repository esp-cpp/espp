Log

Speaks the espp bldc_haptics example's vendor-interface protocol (frame: magic "OT" + flags + module + type + len + payload + CRC-32, dispatcher module 2; see PROTOCOL.md). After an OTA FINISH the device validates the image (SHA-256), sets the boot partition and restarts; with bootloader rollback enabled the new app must mark itself valid or the device rolls back.

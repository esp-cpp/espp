Speaks the espp bldc_haptics example's vendor-interface protocol (frame: magic "OT" + flags + module + type + len + payload + CRC-32, dispatcher module 2; see PROTOCOL.md). The same device also serves firmware update (module 0) and crash-dump inspection (module 4) — use the ota / coredump consoles (or the device hub, which discovers all three).

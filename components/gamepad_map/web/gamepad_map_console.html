The default map applies to every controller without a profile. A profile belongs to one controller type (its USB / Bluetooth VID:PID; by name when both are 0). Loading a controller that has no profile yet starts from the default map; saving creates the profile.

espp Gamepad Map Console · talks to espp::GamepadMapService (components/gamepad_map), which remaps a controller with an espp::GamepadMap and keeps the maps in an espp::GamepadProfiles store. Single-file, offline, no dependencies.

ESPP Documentation#

This is the documentation for the ESP-IDF C++ library espp. ESPP provides additional C++ components and abstractions for building applications from reusable components.

New here? Start with Getting Started. The API Reference groups every component by capability; all supported development boards are collected under Dev Boards (BSPs). Browser tools for interacting with your hardware are collected under Web Apps, and Running espp in QEMU shows how to run espp code with no hardware at all.

WiFi Station (STA)#

The WiFi station enables the ESP to scan for and connect to an exising WiFi access point.

There is an associated menu class espp::WifiStaMenu which provides methods to configure the station settings via a menu interface at runtime.

You can use this class directly, or you can access / manage it via the singleton espp::Wifi class.

class WifiSta : public espp::WifiBase#

WiFi Station (STA)

see https://docs.espressif.com/projects/esp-idf/en/latest/esp32/api-guides/wifi.html#esp32-wi-fi-station-general-scenario

WiFi Station Example#

    espp::WifiSta::Config config{.ssid = "",     // use whatever was saved to NVS (if any)
                                 .password = "", // use whatever was saved to NVS (if any)
                                 .num_connect_retries = CONFIG_ESP_MAXIMUM_RETRY,
                                 .on_connected = nullptr,
                                 .on_disconnected = nullptr,
                                 .on_got_ip =
                                     [&](ip_event_got_ip_t *eventdata) {
                                       logger.info("got IP: {}.{}.{}.{}",
                                                   IP2STR(&eventdata->ip_info.ip));
                                     },
                                 .log_level = espp::Logger::Verbosity::DEBUG};

    espp::WifiSta wifi_sta(config);
    while (!wifi_sta.is_connected()) {
      std::this_thread::sleep_for(100ms);
    }

inline bool connect(std::string_view ssid, std::string_view password)#

Connect to the access point with the given SSID and password.

Note

The SSID and password replace the stored ones completely: a shorter value never keeps the trailing bytes of the previous one. The rest of the stored STA configuration (channel, BSSID, …) is kept.

Parameters:

  • ssid – SSID of the access point (at most 32 bytes).

  • password – Password of the access point (at most 64 bytes). If empty, the AP is open / has no security: the previously stored password is cleared, not kept.

class WifiStaMenu#

A CLI menu for interacting with a WiFi station (STA) mode.

This class provides a CLI menu for interacting with a WiFi station. It provides options for setting the log verbosity, connecting to a WiFi network, disconnecting from a WiFi network, getting the current RSSI (Received Signal Strength Indicator), getting the current IP address, checking if the WiFi is connected, getting the current MAC address, and getting the current WiFi configuration.

Example#

    espp::WifiSta::Config config{.ssid = "",     // use whatever was saved to NVS (if any)
                                 .password = "", // use whatever was saved to NVS (if any)
                                 .num_connect_retries = CONFIG_ESP_MAXIMUM_RETRY,
                                 .on_connected = nullptr,
                                 .on_disconnected = nullptr,
                                 .on_got_ip =
                                     [&](ip_event_got_ip_t *eventdata) {
                                       logger.info("got IP: {}.{}.{}.{}",
                                                   IP2STR(&eventdata->ip_info.ip));
                                     },
                                 .log_level = espp::Logger::Verbosity::DEBUG};

    espp::WifiSta wifi_sta(config);
    auto sta_menu = espp::WifiStaMenu(wifi_sta);
    cli::Cli cli(sta_menu.get());
    cli::SetColor();
    cli.ExitAction([](auto &out) { out << "Goodbye and thanks for all the fish.\n"; });

    espp::Cli input(cli);
    input.SetInputHistorySize(10);
    input.Start();
